# Universal Video Downloader

A desktop app (Tkinter + yt-dlp) for downloading videos from social media and many other websites.

## Setup

1. Install system dependencies:
   ```
   sudo apt update && sudo apt install python3 python3-pip python3-tk ffmpeg
   ```
2. Install Python requirements:
   ```
   pip3 install -r requirements.txt
   ```

## Run

```
python3 main.py
```

## Supported Sites

Uses yt-dlp, which supports hundreds of sites (YouTube, Facebook, Twitter, Instagram, TikTok, Reddit, etc).

See [yt-dlp supported sites](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).
